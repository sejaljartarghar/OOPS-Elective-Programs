# OOPS Elective – C++ Programs

This repository contains C++ programs developed as part of my **Object-Oriented Programming (OOPS) Elective** coursework.

The programs cover fundamental C++ concepts and progress through functions, strings, arrays, classes, constructors, static members, friend functions, and inheritance.

## Repository Structure

```text
OOPS-Elective-Programs/
│
├── Programs/
│   ├── Day_1/
│   ├── Day_2/
│   ├── Day_3/
│   ├── Day_4/
│   ├── Day_5/
│   └── Day_8/
│
├── .gitignore
└── README.md
```

Each folder contains the C++ programs from the corresponding class/session.

## How to Run

Compile any program using:

```bash
g++ filename.cpp -o program
```

Then run:

```bash
./program
```

On Windows:

```bash
program.exe
```
